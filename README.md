## PART 1 – Project Structure

### Answer the following questions
5. Como crear un pull request en Github?
    Para crear un pr vamos a la aplicación de Github, abrimos el repositorio y debajo del boton verde code hacemos click en el boton pull request, saldra una ventana llamada "Open a pull request" donde devemos proveer detalles necesarios de lo que hemos hecho, luego le damos en el boton create pull request
6. Como aprobar un pull request en Github?
    para aprobarlo vamos a la aplicación de Github, abrimos el pull request en el repositorio, damos click en revisar cambios, redactamos un mensaje breve, seleccionamos la casilla aprobar y enviamos la revision
